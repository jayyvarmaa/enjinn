# gameplay

Here lies the gameplay code. All the containers and also some logic used to load them.

New runtime lab containers added:
- `McDungeonsAnimationLab` - animation testing/editing with `mcDungeons/steve.glb`
- `McDungeonsAudioLab` - audible audio lab using a generated runtime loop and reactive stage controls
- `CrabParticleLab` - particle emitter lab with editable styles and a clean studio environment
