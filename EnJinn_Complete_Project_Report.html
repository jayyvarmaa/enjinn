1.3 Abstract

This project presents the design and implementation of a custom 2D/3D game engine built in C++17 with a strong emphasis on runtime control, modular architecture, and memory-aware system design. Instead of relying on monolithic commercial engines, the project develops an internal architecture where gameplay modules are compiled as dynamically loaded containers and executed under an engine-managed runtime.

The engine addresses key challenges commonly hidden in prebuilt engines: deterministic update-loop control, explicit memory ownership and allocator binding, custom rendering integration for both 2D and 3D workloads, and runtime extensibility through DLL-based hot-reload workflows. This report documents the complete technical architecture, implementation decisions, testing strategies, security measures, cost estimations, and future roadmap.

A.2 ComponentPool Hybrid Allocator (Scene Graph Memory)

File: EnJinn/core/sharedRuntime/sceneGraph/node.h

Purpose: Fixed-pool + malloc fallback for component allocation.

// Fixed-size pool with fallback
class ComponentPool {
private:
    static constexpr size_t POOL_SIZE = 1024 * 1024;  // 1 MB
    static constexpr size_t MAX_ALLOC = 4096;          // 4 KB max pool alloc
    
    char pool[POOL_SIZE];
    size_t offset = 0;
    
public:
    void* allocate(size_t size) {
        // 16-byte alignment
        size = (size + 15) & ~15;
        
        // Use pool for small allocations
        if (size <= MAX_ALLOC && offset + size <= POOL_SIZE) {
            void* ptr = pool + offset;
            offset += size;
            return ptr;
        }
        
        // Fall back to malloc for large allocations
        return std::malloc(size);
    }
    
    void deallocate(void* ptr) {
        // Only free heap allocations, not pool blocks
        if (ptr < pool || ptr >= pool + POOL_SIZE) {
            std::free(ptr);
        }
    }
    
    void reset() { offset = 0; }  // Frame reset
};

A.3 Container Allocator Binding Pattern (Memory Isolation)

File: EnJinn/core/enjinnRuntime/containerManager/containerManager.cpp

Purpose: Per-frame allocator binding ensures memory isolation between engine and gameplay.

// Per-container update with explicit allocator binding
void ContainerManager::updateContainer(RuntimeContainer& c, 
                                       const Input& input, 
                                       const WindowState& state) {
    // Bind container's allocator as active realm
    loadedDll.bindAllocatorDllRealm(&c.allocator);
    
    // All std::malloc/new called within gameplay uses c.allocator
    bool success = c.pointer->update(input, state, c.requestedContainerInfo);
    
    // Unbind: subsequent allocations use runtime allocator
    loadedDll.resetAllocatorDllRealm();
    
    // Record timing and status
    c.lastFrameTime = measureFrameTime(success);
}

// This binding/unbinding pattern prevents:
// - Gameplay code leaking allocations into engine realm
// - Engine accidentally using gameplay allocator
// - Cross-container memory interference

A.4 Shader Uniform Location Caching (Rendering Optimization)

File: EnJinn/core/enjinnRuntime/rendering/material.cpp

Purpose: Cache OpenGL uniform locations to avoid repeated queries.

// Shader class with uniform caching
class Shader {
private:
    GLuint programID;
    std::unordered_map<std::string, int> uniformLocations;
    
public:
    // Cached uniform lookup
    int getUniformLocation(const std::string& name) {
        auto it = uniformLocations.find(name);
        if (it != uniformLocations.end()) {
            return it->second;  // Return cached value
        }
        
        // First-time lookup: query OpenGL and cache
        int loc = glGetUniformLocation(programID, name.c_str());
        uniformLocations[name] = loc;
        return loc;
    }
    
    // Shader compilation with status checking
    bool compileShader(unsigned int shaderID, 
                       const std::string& source, 
                       const std::string& type) {
        glCompileShader(shaderID);
        
        GLint success;
        glGetShaderiv(shaderID, GL_COMPILE_STATUS, &success);
        
        if (!success) {
            std::cerr << "Compilation failed (" << type << "): " 
                      << getCompilationErrors(shaderID) << std::endl;
            return false;
        }
        return true;
    }
};

A.5 Scene Graph Node Structure (Hierarchical Organization)

File: EnJinn/core/sharedRuntime/sceneGraph/node.h

Purpose: Hierarchical scene composition with transform inheritance.

// Node in scene hierarchy
class Node {
private:
    Node* parent = nullptr;
    std::vector<Node*> children;
    std::vector<Component*> components;
    
    glm::mat4 localTransform;
    glm::mat4 globalTransform;
    
public:
    // Hierarchy management
    void addChild(Node* child);
    void removeChild(Node* child);
    
    // Component management
    template<typename T>
    T* addComponent() {
        T* comp = new T();
        comp->node = this;
        components.push_back(comp);
        comp->onCreate();
        return comp;
    }
    
    // Transform update with inheritance
    void updateTransforms() {
        if (parent) {
            globalTransform = parent->globalTransform * localTransform;
        } else {
            globalTransform = localTransform;
        }
        
        for (auto child : children) {
            child->updateTransforms();
        }
    }
    
    // Component updates
    void update(float deltaTime) {
        for (auto comp : components) {
            comp->onUpdate(deltaTime);
        }
        for (auto child : children) {
            child->update(deltaTime);
        }
    }
};
