1.1 Memory Management Subsystem

FreeListAllocator: Guard Value Protection Mechanism

The FreeListAllocator implements a free-list memory management strategy with buffer overflow detection via sentinel guard values. Each allocated block is prefixed and guarded by a 64-bit sentinel value (0xffffffffffffffff). Buffer overflows corrupt this guard, enabling immediate detection on deallocation.

File: EnJinn/core/enjinnSTD/enjinnAllocator/freeListAllocator.h (lines 1-120)

// Sentinel guard for detecting buffer overflow and double-free
constexpr uint64_t GUARD_VALUE = 0xff'ff'ff'ff'ff'ff'ff'ff;

// Metadata for free blocks in free list
struct FreeBlock {
    union {
        char* next;              // Pointer to next free block
        std::uint64_t padding;   // Ensure 16-byte size
    };
    std::uint64_t size;          // Size of free block
};

// Metadata for allocated blocks (with guard)
struct AllocatedBlock {
    std::uint64_t size;          // Size of allocated block
    std::uint64_t guard;         // Detectsoverflow/double-free
};

// Main free-list allocator class
struct FreeListAllocator {
private:
    char* baseMemory = nullptr;
    void* originalBaseMemory = nullptr;
    size_t heapSize = 0;
    void* end = nullptr;

public:
    // Initialize allocator with memory region
    void init(void* baseMemory, size_t memorySize);

    // Allocate memory block
    // - Rounds size to 8-byte alignment
    // - Searches free list for adequate block
    // - Returns pointer after guard header
    void* allocate(size_t size);

    // Deallocate memory block
    // - Verifies guard value against GUARD_VALUE
    // - Coalesces adjacent free blocks
    // - Returns block to free list
    void free(void* mem);

    // Query heap fragmentation metrics
    void calculateMemoryMetrics(
        size_t& availableMemory,  // Total free bytes
        size_t& biggestBlock,     // Largest contiguous free region
        int& freeBlockCount       // Number of free blocks
    );

    // If true, return nullptr on OOM instead of crashing
    bool returnZeroIfNoMoreMemory = false;
};

Key Implementation Details:

  • Alignment: All allocations aligned to 8-byte boundaries for natural 64-bit pointer alignment.
  • Guard Placement: Guard value stored immediately before returned pointer; overflow detection is automatic.
  • Fragmentation: Free blocks are coalesced when adjacent; calculateMemoryMetrics() reports fragmentation status.
  • Bounds Checking: Every allocation/deallocation verifies pointer is within [baseMemory, end) range.
ComponentPool: Hybrid Fixed-Pool + Malloc Strategy

The ComponentPool allocates small, fixed-size components from a pre-allocated pool (1 MB) using a simple bump-pointer strategy. Components exceeding MAX_ALLOC (4 KB) fall back to malloc, ensuring both efficiency and flexibility.

File: EnJinn/core/sharedRuntime/sceneGraph/node.h (lines 26-80)

class ComponentPool {
private:
    static constexpr size_t POOL_SIZE = 1024 * 1024;  // 1 MB pool
    static constexpr size_t MAX_ALLOC = 4096;          // 4 KB max for pool
    static constexpr size_t ALIGNMENT = 16;            // 16-byte alignment

    char pool[POOL_SIZE];
    size_t offset = 0;  // Current allocation offset

public:
    // Allocate from pool or malloc
    void* allocate(size_t size) {
        // Align to 16 bytes
        size = (size + (ALIGNMENT - 1)) & ~(ALIGNMENT - 1);

        // Try pool allocation
        if (size <= MAX_ALLOC && offset + size <= POOL_SIZE) {
            void* ptr = pool + offset;
            offset += size;
            return ptr;
        }

        // Fallback to malloc for large allocations
        return std::malloc(size);
    }

    // Deallocate: only free non-pool blocks
    void deallocate(void* ptr) {
        // Check if pointer is in pool range
        if (ptr >= pool && ptr < pool + POOL_SIZE) {
            // Pool blocks are freed en masse on reset
            return;
        }

        // Non-pool blocks use std::free
        std::free(ptr);
    }

    // Frame reset: bulk-free all pool allocations
    void reset() {
        offset = 0;  // Reset bump pointer for next frame
    }

    // Query current usage
    size_t available() const {
        return POOL_SIZE - offset;
    }
};

Rationale:

  • Most components (GenericSprite, GenericPhysics, etc.) fit in 4 KB, avoiding malloc overhead.
  • Per-frame reset is O(1), making bulk deallocation instant.
  • 16-byte alignment ensures SIMD-friendly memory layout.
  • Fallback to malloc handles oversized components gracefully.

1.2 Container Lifecycle and Allocator Binding

Per-Frame Allocator Binding Pattern

Each frame, before updating a container, the runtime binds that container's allocator as the "active" heap. All malloc/new calls within the container update use the container's allocator, not the runtime's. This ensures complete memory isolation.

File: EnJinn/core/enjinnRuntime/containerManager/containerManager.cpp (lines 442-486)

void ContainerManager::updateContainer(RuntimeContainer& c,
                                       const Input& windowInput,
                                       const WindowState& windowState) {
    // Verify container is valid and ready
    if (!c.pointer || c.status == ContainerStatus::Destroyed) {
        return;
    }

    // ========== CRITICAL: Allocator Binding BEGIN ==========
    // Bind container's allocator as global allocation context
    loadedDll.bindAllocatorDllRealm(&c.allocator);

    // All std::malloc, new, operator new() calls within gameplay
    // code will use c.allocator's memory pool, NOT runtime heap

    // Execute container update frame
    bool updateSuccess = c.pointer->update(
        windowInput,              // Input state this frame
        windowState,              // Window dimensions, flags
        c.requestedContainerInfo  // Container metadata
    );

    // ========== CRITICAL: Allocator Binding END ==========
    // Restore runtime allocator as active
    loadedDll.resetAllocatorDllRealm();

    // Container update completed; all gameplay allocations
    // are now confined to c.allocator

    // Record timing metrics
    auto frameTime = measureFrameTime();
    c.lastFrameTime = frameTime;
    if (frameTime > c.maxFrameTime) {
        c.maxFrameTime = frameTime;
    }

    // Update status if container requested shutdown
    if (!updateSuccess) {
        c.status = ContainerStatus::ShutdownRequested;
    }
}

Critical Points:

  • Placement: Binding MUST wrap container.update() call, not initialization or destruction.
  • No Nesting: Binding is not re-entrant; do not call update() recursively.
  • Error Safety: If update() throws, allocator binding is NOT automatically reset. (Future: RAII wrapper)
  • Performance: Binding involves reassigning global allocator pointers; typically negligible overhead (~5 CPU cycles).

1.3 Scene Graph and Component System

Node Class: Hierarchical Transform and Component Aggregation

File: EnJinn/core/sharedRuntime/sceneGraph/node.h (lines 1-150)

// Forward declarations
class Component;
class Scene;

// Hierarchical node in scene graph
class Node {
public:
    // ===== Hierarchy Management =====
    Node* parent = nullptr;
    std::vector<Node*> children;

    void addChild(Node* child) {
        if (!child || child == this) return;
        if (child->parent) child->parent->removeChild(child);

        child->parent = this;
        children.push_back(child);
    }

    void removeChild(Node* child) {
        auto it = std::find(children.begin(), children.end(), child);
        if (it != children.end()) {
            children.erase(it);
            child->parent = nullptr;
        }
    }

    // ===== Component Management =====
    std::vector<Component*> components;

    // Type-safe component addition
    template<typename T>
    T* addComponent() {
        static_assert(std::is_base_of_v<Component, T>, "T must inherit from Component");

        T* component = new T();
        component->node = this;
        components.push_back(component);
        
        component->onCreate();
        return component;
    }

    void removeComponent(Component* comp) {
        auto it = std::find(components.begin(), components.end(), comp);
        if (it != components.end()) {
            (*it)->onDestroy();
            delete *it;
            components.erase(it);
        }
    }

    // ===== Transform Hierarchy =====
    glm::mat4 localTransform = glm::mat4(1.0f);
    glm::mat4 globalTransform = glm::mat4(1.0f);

    void setLocalTransform(const glm::mat4& transform) {
        localTransform = transform;
    }

    void updateTransforms() {
        // Compute global transform from parent
        if (parent) {
            globalTransform = parent->globalTransform * localTransform;
        } else {
            globalTransform = localTransform;
        }

        // Recursively update children
        for (Node* child : children) {
            child->updateTransforms();
        }
    }

    glm::vec3 getGlobalPosition() const {
        return glm::vec3(globalTransform[3]);
    }

    // ===== Update and Render Cycles =====
    void update(float deltaTime) {
        // Update all components
        for (Component* comp : components) {
            comp->onUpdate(deltaTime);
        }

        // Recursively update children
        for (Node* child : children) {
            child->update(deltaTime);
        }
    }

    void render() {
        // Render all components
        for (Component* comp : components) {
            comp->onRender();
        }

        // Recursively render children
        for (Node* child : children) {
            child->render();
        }
    }

    // ===== Serialization =====
    void serialize(std::string& output) {
        // Serialize this node's transforms and components
        output += "Node {\\n";
        output += "  transform: " + serializeMatrix(globalTransform) + "\\n";

        for (Component* comp : components) {
            comp->serialize(output);
        }

        output += "}\\n";

        for (Node* child : children) {
            child->serialize(output);
        }
    }
};

Design Rationale:

  • Composition Over Inheritance: Uses components instead of virtual methods for extensibility.
  • Transform Caching: Global transforms cached and updated hierarchically; avoids recomputation.
  • Recursive Traversal: Depth-first update/render ensures proper execution order.

1.4 Rendering Subsystem

Shader Class: Compilation, Caching, and Uniform Management

File: EnJinn/core/enjinnRuntime/rendering/shader.h (lines 1-120)

class Shader {
private:
    GLuint programID = 0;
    bool linked = false;

    // Uniform location cache
    mutable std::unordered_map<std::string, GLint> uniformLocationCache;

public:
    // Compile and link shader program
    bool compile(const std::string& vertexSource,
                 const std::string& fragmentSource) {
        // Compile vertex shader
        GLuint vertID = glCreateShader(GL_VERTEX_SHADER);
        const char* vSrc = vertexSource.c_str();
        glShaderSource(vertID, 1, &vSrc, nullptr);
        if (!compileShader(vertID, vertexSource, "Vertex")) {
            glDeleteShader(vertID);
            return false;
        }

        // Compile fragment shader
        GLuint fragID = glCreateShader(GL_FRAGMENT_SHADER);
        const char* fSrc = fragmentSource.c_str();
        glShaderSource(fragID, 1, &fSrc, nullptr);
        if (!compileShader(fragID, fragmentSource, "Fragment")) {
            glDeleteShader(vertID);
            glDeleteShader(fragID);
            return false;
        }

        // Link program
        programID = glCreateProgram();
        glAttachShader(programID, vertID);
        glAttachShader(programID, fragID);
        glLinkProgram(programID);

        GLint linkStatus;
        glGetProgramiv(programID, GL_LINK_STATUS, &linkStatus);
        if (!linkStatus) {
            std::cerr << "Shader linking failed: " << getLinkErrors() << std::endl;
            glDeleteProgram(programID);
            return false;
        }

        glDeleteShader(vertID);
        glDeleteShader(fragID);
        linked = true;
        return true;
    }

    // Get uniform location with caching
    GLint getUniformLocation(const std::string& name) const {
        // Check cache first
        auto it = uniformLocationCache.find(name);
        if (it != uniformLocationCache.end()) {
            return it->second;
        }

        // Query OpenGL and cache result
        GLint loc = glGetUniformLocation(programID, name.c_str());
        uniformLocationCache[name] = loc;
        return loc;
    }

    // Set uniform values
    void setUniform1f(const std::string& name, float v0) {
        glUniform1f(getUniformLocation(name), v0);
    }

    void setUniform2f(const std::string& name, float v0, float v1) {
        glUniform2f(getUniformLocation(name), v0, v1);
    }

    void setUniform3f(const std::string& name, const glm::vec3& v) {
        glUniform3f(getUniformLocation(name), v.x, v.y, v.z);
    }

    void setUniformMatrix4f(const std::string& name, const glm::mat4& mat) {
        glUniformMatrix4fv(getUniformLocation(name), 1, GL_FALSE, glm::value_ptr(mat));
    }

    void bind() const {
        glUseProgram(programID);
    }

    void unbind() const {
        glUseProgram(0);
    }

private:
    bool compileShader(GLuint shaderID, const std::string& source, const std::string& type) {
        glCompileShader(shaderID);

        GLint success;
        glGetShaderiv(shaderID, GL_COMPILE_STATUS, &success);

        if (!success) {
            std::cerr << "Shader compilation failed (" << type << "): " << std::endl;
            std::cerr << getCompilationErrors(shaderID) << std::endl;
            return false;
        }

        return true;
    }

    ~Shader() {
        if (programID) {
            glDeleteProgram(programID);
        }
    }
};

Performance Optimizations:

  • Uniform Caching: glGetUniformLocation is cached; avoids repeated OpenGL state queries per frame.
  • Lazy Compilation: Shaders compiled on-demand; errors reported with line numbers.
  • Link Status Checking: glLinkProgram result verified; prevents silent failures.

File: tests/test_allocator.cpp

#include <doctest/doctest.h>
#include "enjinnAllocator/freeListAllocator.h"
#include <vector>

TEST_SUITE("FreeListAllocator") {

    TEST_CASE("Basic allocation and deallocation") {
        char buffer[4096];
        enjinn::memory::FreeListAllocator alloc(buffer, sizeof(buffer));

        void* p1 = alloc.allocate(100);
        REQUIRE(p1 != nullptr);
        REQUIRE(p1 >= buffer && p1 < buffer + sizeof(buffer));

        void* p2 = alloc.allocate(200);
        REQUIRE(p2 != nullptr);
        REQUIRE(p2 > p1);  // Subsequent allocation higher

        alloc.free(p1);
        alloc.free(p2);

        // After freeing, should reuse memory
        void* p3 = alloc.allocate(100);
        REQUIRE(p3 == p1);
    }

    TEST_CASE("Fragmentation and coalescing") {
        char buffer[1024];
        enjinn::memory::FreeListAllocator alloc(buffer, sizeof(buffer));

        // Allocate three blocks
        void* p1 = alloc.allocate(100);
        void* p2 = alloc.allocate(100);
        void* p3 = alloc.allocate(100);

        // Free first and second (should coalesce)
        alloc.free(p1);
        alloc.free(p2);

        // Should be able to allocate 200 bytes from freed space
        void* p4 = alloc.allocate(200);
        REQUIRE(p4 == p1);  // Reuse coalesced block
    }

    TEST_CASE("Alignment verification") {
        char buffer[2048];
        enjinn::memory::FreeListAllocator alloc(buffer, sizeof(buffer));

        void* p1 = alloc.allocate(13);  // Not aligned
        void* p2 = alloc.allocate(27);  // Not aligned

        // Should be aligned to 8 bytes
        REQUIRE(reinterpret_cast<uintptr_t>(p1) % 8 == 0);
        REQUIRE(reinterpret_cast<uintptr_t>(p2) % 8 == 0);
    }

    TEST_CASE("Heap corruption detection (double-free)") {
        char buffer[1024];
        enjinn::memory::FreeListAllocator alloc(buffer, sizeof(buffer));

        void* ptr = alloc.allocate(100);
        alloc.free(ptr);

        // Second free should trigger assertion
        // NOTE: In production, this would crash if ENJINN_PERMA_ASSERT is enabled
        // Test with EXPECT_ASSERT macro if available
        // alloc.free(ptr);  // EXPECT_ASSERT
    }
}

TEST_SUITE("ComponentPool") {

    TEST_CASE("Pool allocation for small components") {
        enjinn::ComponentPool pool;

        void* p1 = pool.allocate(64);    // Fits in pool
        void* p2 = pool.allocate(128);   // Fits in pool
        void* p3 = pool.allocate(256);   // Fits in pool

        REQUIRE(p1 != nullptr);
        REQUIRE(p2 != nullptr);
        REQUIRE(p3 != nullptr);

        // All should be in pool range
        REQUIRE(p1 >= pool.getPoolBase());
    }

    TEST_CASE("Fallback to malloc for large allocations") {
        enjinn::ComponentPool pool;

        void* large = pool.allocate(10000);  // Exceeds MAX_ALLOC
        REQUIRE(large != nullptr);

        // Should use malloc, not pool
        REQUIRE(large < pool.getPoolBase() || large >= pool.getPoolEnd());

        pool.deallocate(large);  // Should call std::free
    }
}

  • Rendering Time: OpenGL draw calls and buffer swaps.
  • Memory Metrics: Per-container heap usage, fragmentation, and allocation count.

5.2 Manual Profiling with Timers

Using a High-Resolution Timer:

#include <chrono>

class ScopedTimer {
private:
    std::string name;
    std::chrono::high_resolution_clock::time_point start;

public:
    ScopedTimer(const std::string& name) : name(name) {
        start = std::chrono::high_resolution_clock::now();
    }

    ~ScopedTimer() {
        auto end = std::chrono::high_resolution_clock::now();
        auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
        std::cout << name << ": " << duration.count() << " µs" << std::endl;
    }
};

// Usage in code:
void Container::update(...) {
    {
        ScopedTimer timer("Scene Update");
        scene.update(deltaTime);
    }

    {
        ScopedTimer timer("Rendering");
        scene.render();
    }
}

6.1 Using Assertions for Development

// ENJINN_PERMA_ASSERT: Always enabled, even in release builds
ENJINN_PERMA_ASSERT(baseMemory != nullptr, "Allocator not initialized");

// ENJINN_DEBUG_ASSERT: Only in debug builds

if (!ENJINN_PERMA_ASSERT_EXPR(pointer != nullptr)) {

Appendix 7: Troubleshooting Guide

7.1 Common Build Errors

ErrorCause & Solution
error: C++17 required Add set(CMAKE_CXX_STANDARD 17) to CMakeLists.txt.
undefined reference to GLFW function GLFW not linked. Ensure find_package(glfw3 CONFIG REQUIRED) and link in CMakeLists.txt.
GLAD init failed (glfwGetProcAddress error) OpenGL context not current. Call glfwMakeContextCurrent(window) before gladLoadGLLoader.
DLL load failed / GetProcAddress failed for export Gameplay DLL not compiled with correct export macros. Use extern "C" and __declspec(dllexport) on Windows.

7.2 Runtime Issues

SymptomDiagnosis & Fix
Window doesn't open Check GLFW initialization status in logs. Verify graphics drivers are up-to-date.
Black/garbled rendering Shader compilation failed (check console). Verify OpenGL is version 4.1+. Check texture binding.
Crash at container update Double-check allocator is bound before update. Check for null pointer dereferences in container code.
Memory leak detected on exit Verify all nodes/components are deleted in Container::destruct. Check for circular references.
High frame time jitter Check for per-frame allocations causing fragmentation. Use ComponentPool for small objects. Profile with Profiler window.

7.3 Memory Debugging

To debug memory issues:

  1. Enable ENJINN_DEVELOPMENT=ON for assertion support.
  2. Check Profiler window for fragmentation trends.
  3. Add calculateMemoryMetrics() calls in Container::update().
  4. Use AddressSanitizer (if on Linux/macOS): -fsanitize=address compiler flag.
  5. Review allocator logs for unexpected allocation patterns.
